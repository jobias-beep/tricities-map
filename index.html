      Map data

      Property lines come straight from public government records each time you open an area.

      Settings

      Backup

      Customers are saved in this browser on this computer. Download a backup now and then, and restore it on another device.

      Calendar

      Each property card has an Add to Google Calendar button for its next visit. You can also download every upcoming visit as one calendar file to import into Google Calendar.

      Route planning

      Without a key, Route orders stops by straight-line distance. A free openrouteservice key orders them by actual driving time.

      1. Sign up free at openrouteservice.org.
      2. Open your dashboard and copy the API key.
      3. Paste it here.
      Street View inside the card

      Without a key, Street View opens in a new Google Maps tab. With a free Google Maps Embed key it shows right inside the property card.

      1. Sign in at Google Cloud Console.
      2. Turn on Maps Embed API (no charge for embeds).
      3. Create an API key and paste it here.
